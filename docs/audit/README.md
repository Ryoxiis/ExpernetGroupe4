# Rapports de la maquette source

Ces documents conservent l’inventaire et les constats faits sur la V2 statique.
Les anciennes références à `dist/` ou `build.py` y décrivent la maquette de départ,
pas l’organisation de ce starter PHP. La table des routes actuelle est
`config/routes.json` ; les consignes de développement sont à la racine et dans
`docs/ARCHITECTURE.md`.

Les anomalies de dates, de PDF et de doublons dans le site source restent à vérifier
auprès d’Expernet avant toute modification des contenus.
