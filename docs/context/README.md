# Contexte de cours et instructions IA

Les règles et le skill actifs du projet se trouvent dans `.ai/`, dossier local
ignoré par Git. Les anciennes copies rules.md et SKILL.md de ce dossier ont été
retirées pour éviter des instructions contradictoires.

Lire AGENTS.md à la racine. Le dossier `.ai/` regroupe les règles du remplacement
de GALIA, le design V2 Océan et les conventions de développement. Il doit être
transmis séparément à un collègue : un clone Git ne le récupère pas.

Les documents du dossier de cours parent restent des sources historiques. La
correction explicite du propriétaire prévaut : aucun fichier 67.php ni motif
banane à créer. Le PDF du sujet reste à son emplacement dans le dossier parent.
